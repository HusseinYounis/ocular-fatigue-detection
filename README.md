# Ocular Fatigue Detection via EOG Signal Analysis

Detects eye fatigue from vertical electrooculography (EOG) signals using machine learning. The pipeline extracts blink-based features from raw EOG windows and trains a classifier to distinguish rested from fatigued eye states. Designed to run on both desktop (training) and embedded hardware (inference).

## Signal Processing Pipeline

Each segment is preprocessed before windowing:

```
Raw EOG segment
      │
      ▼
 Remove DC offset (subtract segment mean)
      │
      ▼
 4th-order Butterworth bandpass — SOS form
 0.3 Hz  ────────────────────  12 Hz
  └─ keeps blink frequencies        └─ rejects EMG & high-freq noise
      │
      ▼
 Slice into 10-second windows (10,000 samples each)
      │
      ▼
 Extract features per window
```

> **Why SOS form?** A 0.3 Hz lower cutoff in a direct `(b, a)` Butterworth causes numerical overflow. Second-order sections (`output='sos'` + `sosfiltfilt`) are always numerically stable regardless of cutoff frequency.

## Features Extracted

Per 10-second window:

| Feature | Description |
|---------|-------------|
| `Blink_Rate_bpm` | Blinks per minute (peak detection on z-score signal) |
| `Mean_Blink_Amplitude` | Average z-score height of detected blink peaks |
| `OCI` | Ocular Closure Index — % of window estimated as eyes-closed (200 ms × blink count / window duration) |
| `RMS` | Root mean square of filtered signal amplitude |
| `Std_Dev` | Standard deviation of filtered signal |
| `Dominant_Freq_Hz` | Frequency with highest spectral power (excluding DC) |
| `Energy_0.1_0.5Hz` | Spectral energy in the blink frequency band (0.1–0.5 Hz), computed on z-score signal |

### Blink Detection Parameters

- **Prominence ≥ 2.5 SD** above local baseline (rejects noise spikes)
- **Minimum inter-blink distance: 300 ms** (physiological minimum)
- Normal resting blink rate: 10–20 bpm; fatigue may increase or decrease this

## Labeling Strategy

Labels come directly from the experiment design — **no formula-based approximation**:

- **Label 0 (no fatigue):** Basal segment — participants at rest with eyes open for 60 seconds
- **Label 1 (fatigue):** Test segments — sustained visual fixation task inducing progressive ocular fatigue

This is grounded in the original study protocol. The basal state IS the ground-truth non-fatigued condition; the fixation tasks ARE the fatigue-inducing condition.

### Class Distribution

| Class | Windows | % |
|-------|---------|---|
| 0 — no fatigue | 5 | 12% |
| 1 — fatigue | 37 | 88% |

The imbalance reflects the experimental ratio (1 min baseline vs. ~6 min of tests). It is handled with `class_weight='balanced'` in all classifiers.

> **Note:** This dataset has only 42 windows total from 4 participants. Results should be considered a proof-of-concept. For a production system, collect more data from more subjects.

## Model Training & Evaluation

Three classifiers are compared using **3-fold stratified cross-validation** (more reliable than a single split given the small dataset):

| Model | Metric |
|-------|--------|
| Random Forest | Weighted F1 |
| Support Vector Machine (RBF kernel) | Weighted F1 |
| Gradient Boosting | Weighted F1 |

All features are normalized with `StandardScaler` before training. The best model by cross-validation is then re-evaluated on a held-out 20% test set.

## Hardware Integration (BioAmp EXG Pill + ESP32)

### Compatibility

| Aspect | BIOPAC (dataset) | BioAmp EXG Pill + ESP32 |
|--------|-----------------|------------------------|
| Electrode placement | Vertical periorbital | Same ✅ |
| Signal physics | Vertical EOG | Same ✅ |
| Sampling rate | 1000 Hz | Achievable via hardware timer ✅ |
| ADC resolution | Medical-grade 16-bit | 12-bit (0–4095, 0–3.3 V) |
| Raw amplitude | ±0.5 mV differential | Amplified to ±1–1.5 V (gain ~1000×) |
| Noise floor | Very low | Higher; depends on shielding |

The pipeline is **amplitude-invariant** because DC removal and z-score normalization are applied before feature extraction. The trained model generalises to BioAmp output without retraining.

---

### Electrode Wiring

```
BioAmp EXG Pill         Electrode position
─────────────────       ──────────────────────────────
IN+          ──────────  Supraorbital (above pupil)
IN-          ──────────  Infraorbital (below eye)
REF          ──────────  Outer canthus (right eye)
GND          ──────────  Patient ground / body ground
OUT          ──────────  ESP32 ADC pin (e.g. GPIO34)
3.3V / 5V    ──────────  ESP32 3.3V or 5V (check your board version)
GND          ──────────  ESP32 GND
```

> Use **Ag/AgCl disposable gel electrodes** (same type as the dataset). Clean the skin with alcohol before placement to reduce impedance.

### ESP32 Firmware Sketch

```cpp
#include <Arduino.h>

// ── Configuration ────────────────────────────────────────────────────────────
const int    ADC_PIN       = 34;      // BioAmp output → GPIO34 (input-only pin)
const int    FS_HZ         = 1000;    // sampling frequency
const int    WINDOW_S      = 10;      // window length in seconds
const int    WINDOW_N      = FS_HZ * WINDOW_S;  // 10,000 samples

float        window[WINDOW_N];        // circular buffer
int          sampleIndex = 0;
bool         windowReady = false;

hw_timer_t  *timer = NULL;
portMUX_TYPE timerMux = portMUX_INITIALIZER_UNLOCKED;
volatile bool takeSample = false;

// ── Timer ISR — fires every 1 ms ─────────────────────────────────────────────
void IRAM_ATTR onTimer() {
    portENTER_CRITICAL_ISR(&timerMux);
    takeSample = true;
    portEXIT_CRITICAL_ISR(&timerMux);
}

void setup() {
    Serial.begin(115200);
    analogReadResolution(12);          // 12-bit ADC (0–4095)
    analogSetAttenuation(ADC_11db);    // full 0–3.3 V range

    // Hardware timer at 1000 Hz (period = 1,000 µs)
    timer = timerBegin(0, 80, true);   // 80 MHz / 80 = 1 MHz tick
    timerAttachInterrupt(timer, &onTimer, true);
    timerAlarmWrite(timer, 1000, true); // 1000 ticks = 1 ms
    timerAlarmEnable(timer);
}

void loop() {
    if (!takeSample) return;

    portENTER_CRITICAL(&timerMux);
    takeSample = false;
    portEXIT_CRITICAL(&timerMux);

    // Read ADC and convert to millivolts relative to midpoint (1.65 V)
    int   raw    = analogRead(ADC_PIN);
    float volt   = (raw / 4095.0f) * 3300.0f;   // ADC → mV (0–3300 mV)
    float amp_mV = (volt - 1650.0f) / 1000.0f;  // subtract bias, convert to mV
    // NOTE: divide by your BioAmp gain if known (typical ≈ 1000)

    window[sampleIndex++] = amp_mV;

    if (sampleIndex >= WINDOW_N) {
        sampleIndex = 0;
        windowReady = true;
    }

    if (windowReady) {
        windowReady = false;
        sendWindowToSerial();          // or run on-device inference here
    }
}

// Send window over Serial for Python to read (CSV row per sample)
void sendWindowToSerial() {
    Serial.println("WINDOW_START");
    for (int i = 0; i < WINDOW_N; i++) {
        Serial.println(window[i], 4);
    }
    Serial.println("WINDOW_END");
}
```

### Python Inference Bridge

Once a window arrives over serial, pass it through the same preprocessing and feature extraction pipeline from [train.py](./train.py):

```python
import serial
import numpy as np
import joblib                    # pip install joblib
from train import preprocess, extract_features, FEATURE_COLS

# Load the trained model and scaler (save them first — see below)
model  = joblib.load("model.pkl")
scaler = joblib.load("scaler.pkl")

def predict_window(raw_samples: list[float]) -> int:
    """Returns 0 (no fatigue) or 1 (fatigue) for a 10-second window."""
    sig    = preprocess(np.array(raw_samples))
    feat   = extract_features(sig)
    X      = np.array([[feat[c] for c in FEATURE_COLS]])
    X_sc   = scaler.transform(X)
    return int(model.predict(X_sc)[0])

# Read from ESP32 serial port
port = serial.Serial("COM3", 115200, timeout=5)   # adjust COM port
buf  = []
reading = False

while True:
    line = port.readline().decode().strip()
    if line == "WINDOW_START":
        buf, reading = [], True
    elif line == "WINDOW_END" and reading:
        reading = False
        if len(buf) == 10000:
            label = predict_window(buf)
            print("FATIGUE DETECTED" if label == 1 else "Eyes OK")
        buf = []
    elif reading:
        try:
            buf.append(float(line))
        except ValueError:
            pass
```

### Hardware Tips

| Issue | Solution |
|-------|----------|
| 50/60 Hz power-line noise | Keep signal wires short; use shielded cable; avoid routing near power lines |
| High DC offset on ESP32 ADC | Ensure BioAmp REF electrode is well attached; add a 10 µF capacitor at ADC input |
| ESP32 ADC non-linearity | Avoid readings below ~200 or above ~3800 raw counts; keep BioAmp gain so blinks stay in mid-range |
| Motion artifacts | Ask subject to minimise head movement during recording |
| Dry skin / high impedance | Clean skin with alcohol; use gel electrodes; check impedance < 10 kΩ |
